# Agenda de Salão

Projeto focado no agendamento de horários e recursos (salas, espaços, profissionais). 
Esta aplicação está sendo desenvolvida com base em metodologia ágil e versionamento incremental.

## Estrutura de Pastas

- `backend/`: Código referente à API e banco de dados.
- `frontend/`: Código referente à interface do usuário.

## Configuração Local

1. Ative o ambiente virtual para o backend:
   ```bash
   source venv/bin/activate
   ```
2. Instale as dependências (em breve).
